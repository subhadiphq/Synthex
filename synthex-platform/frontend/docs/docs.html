Synthex API Reference

Multi-agent AI platform API. OpenAI-compatible. Many minds. One answer.

Authentication

Include your sx-... API key as a Bearer token in all requests.

Authorization: Bearer sx-your-key-here

Endpoints

POST /v1/messages

Main synthesis endpoint. Runs multi-agent pipeline.

curl https://your-backend.railway.app/v1/messages \
  -H "Authorization: Bearer sx-..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "synthex-nova-pro",
    "messages": [{"role": "user", "content": "Explain quantum computing"}],
    "max_tokens": 1000
  }'
POST /v1/chat/completions

OpenAI-compatible endpoint. Drop-in replacement — change only base_url.

import openai

client = openai.OpenAI(
    api_key="sx-your-key",
    base_url="https://your-backend.railway.app/v1"
)

response = client.chat.completions.create(
    model="synthex-nova-pro",
    messages=[{"role": "user", "content": "Hello!"}]
)
POST /v1/keys

Create a new API key. The full key is returned only once — save it immediately.

curl -X POST https://your-backend.railway.app/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"name": "My Key", "email": "you@email.com", "plan": "free"}'
GET /v1/usage

Get usage statistics for your API key.

GET /health

Check if the Synthex backend is running. No auth required.
